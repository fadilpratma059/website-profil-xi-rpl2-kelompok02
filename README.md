1.Perbedaan Bekerja Sendiri vs. Menggunakan Git dan GitHub

-Bekerja Sendiri: Semua file disimpan secara lokal. Tidak ada riwayat versi yang terstruktur (sering kali harus membuat file manual seperti revisi_v1, revisi_final). Jika terjadi kesalahan, sulit untuk mengembalikan kode ke kondisi semula.

-Menggunakan Git & GitHub: Setiap perubahan tercatat secara rapi dalam riwayat commit. Anggota tim bisa bekerja pada bagian kode yang berbeda secara simultan tanpa takut menimpa pekerjaan orang lain.

2.Apa manfaat branch?
-Mengisolasi pengerjaan fitur baru, perbaikan bug (bugfix), atau eksperimen agar tidak langsung mengganggu kode utama (main/master) yang sudah stabil.
-Memungkinkan beberapa pengembang mengerjakan fitur berbeda secara paralel di branch masing-masing.

3.Mengapa Pull Request diperlukan?
-sebagai mekanisme pengajuan untuk menggabungkan kode dari branch fitur ke branch utama.
-Memberikan ruang bagi tim untuk meninjau, mendiskusikan, dan menguji kode sebelum benar-benar disatukan, sehingga meminimalkan potensi error atau kerusakan aplikasi.

4.Apa manfaat code Review?
-Menjaga Kualitas Kode: Memastikan kode sesuai standar tim dan bebas dari bug sebelum dimasukkan ke aplikasi utama.
-Transfer Pengetahuan: Anggota tim bisa saling belajar pendekatan coding baru, trik optimasi, atau memahami logika yang dibuat oleh rekan kerjanya.

5.Error yang Paling Sulit Diselesaikan
Bingung diawal karena tidak tahu hrus mulai dari mana

6.Cara Menemukan Solusinya  
-bertanya/berdiskusi bersama anggota kelompok

7.Kontribusi Terbesar dalam Kelompok?
-saya membuat fitur kontak yang setiap anggotanya berisi nama,email,no watsApp dan nama instagram.

8.Jika menjadi programmer profesional, kebiasaan apa dari kegiatan ini yang akan kalian pertahankan?
-Commit Teratur dan Deskriptif: Selalu melakukan commit kecil (atomic commit) dengan pesan penjelasan yang jelas.
-Bekerja Lewat Branch & PR: Tidak pernah langsung mendorong (push) kode ke branch main.
-Disiplin Code Review: Selalu meminta rekan tim meninjau kode sebelum menggabungkannya (merge).
