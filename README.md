 1.Apa arti hasil git status ?

Hasil git status menunjukkan bahwa repository berada pada branch main dan tidak ada perubahan yang belum di-commit.

2.Mengapa setiap developer tidak langsung bekerja pada main?  
-Karena setiap developer memiliki tugas yang berbeda. Dengan menggunakan branch masing-masing, perubahan di kerjakannya secara terpisah jadi tidak mengganggu pada branch main/utama.

4.Apa fungsi git pull?  
-git pull digunakan untuk mengambil perubahan terbaru dari repository remote dan menggabungkannya ke repository lokal.

5.Apa yang terjadi jika programmer tidak melakukan git pull?  
-Programmer dapat menggunakan kode yang sudah tidak terbaru sehingga perubahan dari anggota lain belum tersedia di repository lokal dan dapat menyebabkan masalah saat melakukan kolaborasi.

6.Mengapa main harus dijaga agar tetap stabil?  
-Karena main merupakan branch utama yang berisi hasil pengembangan yang sudah digabungkan. Menjaga main tetap stabil membantu mencegah kode yang bermasalah mengganggu hasil kerja seluruh tim.

1.Apa perbedaan bekerja sendiri dengan bekerja menggunakan Git dan GitHub?  
-Kalau bekerja sendiri biasanya lebih simpel karena semua pekerjaan dikerjakan di satu tempat dan tidak perlu mengatur perubahan dari orang lain. Sedangkan kalau menggunakan Git dan GitHub, kita bisa bekerja bersama dalam satu project tanpa takut perubahan dari anggota lain hilang. Selain itu, setiap perubahan juga bisa dilihat dan dikembalikan kalau terjadi kesalahan.

2.Apa manfaat branch?  
-Manfaat branch yaitu kita bisa merubah,mencoba/demo projeck di main tanpa mengubah projeck utamanya

3.Mengapa Pull Request diperlukan?  
-Pull Request diperlukan supaya perubahan yang kita buat bisa diperiksa dulu oleh anggota lain sebelum digabungkan ke project utama. Dengan begitu, kalau ada kesalahan atau bagian yang kurang, masih bisa diperbaiki terlebih dahulu.

4.Apa manfaat Code Review?  
-Code Review membantu menemukan kesalahan dalam kode yang mungkin tidak kita sadari sendiri. Selain itu, kita juga bisa mendapatkan saran dari anggota lain dan belajar cara membuat kode yang lebih baik.
